# Every dollar figure is labelled Measured Waste or Estimated Saving

Dwight never shows a savings number without saying which kind it is. Measured Waste (Redundant Read, Cache Miss, Runaway Loop) is arithmetic on token counts and holds up in front of a skeptical CFO. Estimated Saving (Model Overkill) relies on a model's judgement about what the work needed, so it is shown and totalled separately. We considered counterfactual replay, which would re-run expensive Sessions on a cheaper model and grade whether the results match, to turn Estimated Savings into measured ones. We cut it for hackathon scope; it's the natural way to upgrade Model Overkill later.


UI note (2026-09-27): labelling every Measured figure buried the page in badges, so Measured is the dashboard default and only Estimated figures carry a visible label. A legend in the header says so, and every figure still carries its kind in its tooltip and accessible name.
