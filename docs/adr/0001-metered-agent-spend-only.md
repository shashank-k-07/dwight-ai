# Scope is metered agent spend, not seat-licensed AI tools

Dwight only observes Agents that bill by usage (coding agents, internal agents on the Customer's own API keys). Seat-licensed chat tools such as ChatGPT Enterprise and Copilot seats are out of scope. With a flat seat price, a wasted token costs the Customer nothing extra, so the problem there is licence management, which is a different product. Metered agent spend is where the same work varies 10–100x in cost and where Waste turns straight into dollars.
